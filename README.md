# Portfólio — Pedro Soares

Site estático publicado via GitHub Pages (pasta `docs/`).

- `config.json` — nome, textos do topo, contatos e ordem dos projetos
- `docs/img/<projeto>/` — prints + `meta.json` (título, problema, funcionalidades, stack, legendas)
- `python build.py` — regenera `docs/index.html`

Todas as telas usam dados fictícios, tema escuro e nome da empresa borrado.
